# Preschool Color & Shape Sorter 🎨🧩

A fun, interactive, and kid-friendly browser game designed for preschoolers (ages 3–5) to practice color matching, hand-eye coordination, and problem-solving.

## Features
* **Simple Touch & Drag Controls:** Built specifically for small hands using a mouse, trackpad, or touchscreen tablet/phone.
* **Gentle Feedback:** If a block is dropped in the wrong spot, it politely bounces back to the top instead of showing a frustrating "Game Over" screen.
* **Celebratory Reward:** Unlocks a cheerful success message once all shapes are matched correctly!
* **Zero Installation:** Runs entirely inside any modern web browser.

---

## How to Play
1. **Open the Game:** Double-click the `index.html` file to open it in your web browser (Chrome, Safari, Edge, or Firefox).
2. **Drag the Blocks:** Click and hold (or tap and hold) any of the colored blocks at the top of the screen.
3. **Match the Colors:** Drag the block down into its corresponding colored target box at the bottom and let go.
4. **Win!** Match all three blocks to complete the game. Refresh the page to play again!

---

## Technical Details
* **Built With:** HTML5 Canvas, Vanilla JavaScript, and CSS.
* **Dependencies:** None! It requires no external libraries or backend servers.
